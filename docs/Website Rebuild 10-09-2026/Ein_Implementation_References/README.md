# Ein implementation references

Use these with Ein Build Brief. The CSV files define records, analytics events and dashboard metrics. The acceptance register starts with every case not run; record actual staging evidence there. Communication templates include route, timing, purpose and required action keys. They are disabled pending exact-version approval and route tests.

The unsubscribe action key must be rendered as a signed one-action link by the chosen email integration; no literal token belongs in a sent email. Reply handling, suppression and sender verification are launch dependencies. Choose and document the technology stack against the functional contracts in the brief.
