# LC-OCT-D11 What evidence would you ask for?

A release discussion needs evidence about behaviour, not only an impressive example.

I would want to see where the system succeeds, what it fails on and what happens when its tools or evidence are uncertain. A team should be able to explain which result would change its decision.

## Spoken script

What evidence would make you comfortable with an agent’s next release?

I would start with the task it is supposed to perform, then look at the behaviour behind the final answer. Did it use the right evidence? Did it call the permitted tools? What happened when a tool failed or returned an uncertain result?

For an illustrative returns assistant, a polite answer is not enough. I would want to know whether it applied the relevant policy and whether a repeated request could lead to a repeated action.

Then I would ask the team which finding would change the design. Maybe the workflow needs a review point. Maybe the permission is too broad. Maybe the evaluation is missing a class of failures.
