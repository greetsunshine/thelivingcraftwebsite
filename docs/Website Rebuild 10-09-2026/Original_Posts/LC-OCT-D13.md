# LC-OCT-D13 A cheaper response can cost more

A lower model bill does not settle the cost of an agentic workflow.

I would also examine retries, human review, latency and the consequence of an incorrect action. An apparently cheap path may create expensive rework. A more capable model may still be unnecessary for a bounded task.

The design discussion needs a defined task and evidence. Decide which cost you are optimising and which risk you are willing to carry, then make the trade-off explicit.
