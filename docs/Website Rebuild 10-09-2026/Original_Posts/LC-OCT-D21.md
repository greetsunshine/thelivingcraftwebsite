## Spoken script

Before an agent changes something outside the model, I want to know how that action is controlled.

Think about sending a message, granting access or issuing a refund. If the tool times out, the agent may not know whether the action succeeded. Simply trying again can create a different problem.

In an illustrative review, I would ask four questions. Who grants the authority? What evidence is required? How do we recognise a repeated request? And who decides what happens when the result is uncertain?

Those answers should shape the tool and workflow. A reassuring sentence in a prompt does not establish the action’s actual boundary. The team needs observable behaviour it can examine and explain.
