# LC-OCT-D09 A useful evaluation changes a decision

Imagine an assistant ending a returns conversation with a lovely answer. Clear, polite, reassuring.

Then you discover it used the wrong policy.

The customer liked the conversation. The review now has a different problem to solve.

That is why I want to look behind the final answer. What was the task? Which evidence did the system use? What did the tool actually do? Was the outcome right?

Once we can see that path, we can make a useful change: narrow a permission, fix the workflow or add a review point.
