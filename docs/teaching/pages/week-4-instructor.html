↔ 00:21 · one stream, four layers outside it

What prompt injection is, and the four places to stop it

Why the model cannot tell your text from theirs

Code and data share one stream of tokens. Tags help the model guess.

The two kinds

Direct: typed into a field the agent reads. Indirect: written where it fetches later.

The four places to stop it

Check the input, fence it, check the action in code, check the output. The prompt line is none of them.

› The wrong answer, and what is right about it

"Wrap the untrusted parts in tags and tell the model to ignore instructions inside them." The field calls it spotlighting.

What is right. It lowers the rate, sometimes a lot. The 2024 paper that named the technique reports attack success falling from above 50% to below 2% on its own tests, and at 00:26 it cuts forged tool output from 40 in 40 to 2 in 40.

What is wrong. It is still a sentence the model weighs. The payload split through the note still gets through 25 times in 40 with it.

What the table says

Topic quiz: direct injection

Question 1 · this topic

Week 2’s override attack was refused 0 in 40 with the prompt line. What did the line do?

The answer.

Nothing you can see. The model also refused it 0 in 40 without the line. On no vector did the line make a change that a second recording reproduced.

The likely wrong answer. "It stopped the attack."

What is right about it. The attack was stopped. The line was not the reason. Only a run without the line can tell you that.

Question 2 · this topic

Which shape of attack got past the prompt line on DeepSeek: orders, or evidence?

The answer.

Evidence. Forged tool output, a split payload and invented UPI references got through on 39 or 40 runs in 40. Every order-shaped attack got nothing, apart from the delimiter hijack's 2 in 40 without the line.

The likely wrong answer. "Encoded or translated orders."

What is right about it. Those are the famous bypasses, and they work on some models. On this one they got nothing. The model you test is the only one the answer is true for.

Question 3 · from earlier

Week 2, 03:18: "Two models reading one attacker-written field are one control, not two."

You put a classifier model in front of the agent. Is that a second control?

The answer.

It is a second reader of the same text, so the same text can persuade it. It lowers the rate and has its own miss rate. Invented evidence contains nothing for it to flag.

The likely wrong answer. "Yes, because it is a different model."

What is right about it. Different models miss different wordings, so the combined rate does fall. Both are still reading words the attacker wrote.
