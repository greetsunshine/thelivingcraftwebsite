# The Living Craft — Design and Asset References

## Canonical visual direction

- Warm ivory/cream backgrounds.
- Forest/deep green, antique gold, dark ink, and sage accents.
- Serif headings paired with clean sans-serif body text.
- Generous whitespace and understated borders.
- Technical diagrams should prioritize legibility, explicit labels, directional arrows, and accurate token/authorization semantics over decoration.

## Existing repository assets

The existing website's shared assets remain in the root `assets/` directory. Do not duplicate or overwrite them as part of course authoring. Before using any shared asset in a new page, inspect `assets/README.md` and existing site conventions.
